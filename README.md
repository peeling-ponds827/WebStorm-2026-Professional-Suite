## Frequently Asked Questions

### Is this suite compatible with my existing WebStorm projects?
Yes, the suite is designed to be compatible. The installed plugins and settings are additive. You can selectively enable or disable specific components from the suite through WebStorm's settings menu without affecting your existing project configurations.

### Do I need an internet connection for the tools to work after installation?
No, once the suite is successfully installed, all core features, templates, and tools operate entirely offline. An internet connection is only required for the initial download of the installer and for WebStorm's own periodic updates, if you choose to enable them.

### How do I uninstall the suite or specific components?
You can manage the installed components through WebStorm's `Settings/Preferences > Plugins` menu. To remove the entire suite, you can use the standard Windows 'Add or remove programs' feature to uninstall the `WebStorm 2026 Professional Suite` package, and then uninstall any residual plugins from within WebStorm itself.
